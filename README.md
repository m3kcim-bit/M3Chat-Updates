# M3Chat

M3Chat — приложение для стримеров, объединяющее чаты Twitch, YouTube и VK Видео Live, с поддержкой OBS и дополнительных модулей.

## Скачать приложение

Актуальная версия доступна в разделе [Releases](https://github.com/m3kcim-bit/M3Chat-Updates/releases).

## Автоматические обновления

Данный репозиторий предназначен для распространения официальных сборок и автоматических обновлений M3Chat.

Исходный код приложения не публикуется.
